# LITEARN — AI Learning Assistant (Streamlit prototype, freemium)

Aplikasi prototype Streamlit untuk merangkum teks, membuat latihan soal adaptif, dan menyimpan progres belajar.
Freemium: 5 kali pemakaian AI gratis; setelah itu butuh upgrade.

## File utama
- `app.py` — Streamlit app (UI + navigasi)
- `utils.py` — DB, pemakaian, summarization & quiz generator
- `requirements.txt` — dependencies
